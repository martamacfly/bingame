Jugar en pareja

Este es el código de tu cartón. Si tu pareja lo mete en su móvil, tendréis el mismo cartón y será una carrera. Si preferís cartones distintos, que cada uno pulse «Cartón nuevo».

----

Tus propias casillas

Añade cosas de tu barrio o bromas vuestras, una por línea. Se mezclan con las de serie.

Para compartir código, los dos tenéis que tener las mismas casillas propias (o ninguna).

Cómo se juega

  1. Elige tamaño: 3×3 para un paseo corto, 5×5 para una tarde entera.
  2. Toca una casilla cuando veas eso por la calle. Si te equivocas, tócala otra vez.
  3. Fila, columna o diagonal completa: ¡línea!
  4. Todo el cartón tachado: ¡BINGO! El que lo canta primero, invita al café.
